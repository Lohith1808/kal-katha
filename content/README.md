# Verified Historical Content Guidelines

All files within this directory structure represent documented historical records for Kal Katha.

## Rules (from AGENTS.md)
1. Historical truth is the source of truth.
2. Never invent historical events, dates, people, locations, or outcomes.
3. Historical content must come only from verified project content files.
4. Keep historical content separate from gameplay and presentation code.
5. Ancient, Medieval, and Modern history must remain separately categorized in their respective subdirectories.
6. Every historical chapter and record must support documented academic or archival source references.

## Directory Structure
- `ancient/`: Verified historical data for the Ancient era.
- `medieval/`: Verified historical data for the Medieval era.
- `modern/`: Verified historical data for the Modern era.
